# 6. Fee Information

## Status

**CONFIRMATION REQUIRED**

### Important Rule

The voice agent must not provide a definitive current B.Tech admission fee unless the amount has been verified for the relevant academic year and admission category.

### Official Reference Information

ACET's mandatory disclosure page lists:

- B.Tech: ₹53,500

This figure is an official reference value on the ACET mandatory disclosure page, but it must not automatically be presented as the current admission fee because the same source refers to an admission policy closed with effect from AY 2025–26.

Therefore:

**B.Tech fee status: CURRENT CONFIRMATION REQUIRED**

### Historical / Individual Fee Reference

A student fee ledger supplied during project development contains historical/individual fee components:

- Tuition Fee: ₹26,750 per semester
- Campus Recruitment Training: ₹7,500
- Textbooks & Printed Books: ₹420 or ₹540 depending on the semester
- Uniform: ₹1,800

These figures are **not** to be presented as the current official B.Tech admission fee.

Individual receipt numbers, payment dates, payment status, outstanding balances, and other personal financial information must **not** be stored in the public project repository or exposed by the voice agent.

### Agent Response

If a user asks:

> "What is the current B.Tech fee?"

The agent should:

1. Check whether a current verified fee is available.
2. If verified, provide the applicable fee and academic year/category.
3. If not verified, do not guess.
4. Explain that current fee confirmation is required.
5. Offer to create a support request.
6. Collect the user's name and contact information if they want follow-up.

### Example Safe Response

> "I don't want to give you an outdated fee amount. The current B.Tech fee depends on the applicable academic year and admission category. I can help you raise a fee enquiry with the college support team."

# 9. Human Escalation

The agent must offer human assistance when:

- The requested information is not in the knowledge base.
- Current information is required.
- The user asks about fees that require confirmation.
- The user asks about current admission deadlines.
- The user asks about seat availability.
- The user has a payment-related problem.
- The user reports a technical or administrative problem.
- The user explicitly asks to speak to a human.
- The user's question is unclear or sensitive.

# 10. Support Request Information

When creating a support request, the agent should collect only the information necessary for the request.

### Required

- Name
- Phone number
- User's B.Tech program, if applicable
- Enquiry/problem description

### Optional

- Year/batch
- Preferred contact method

Before submitting the request, the agent must confirm the collected information with the user.

# 11. Knowledge Base Safety Rules

The voice agent must follow these rules:

1. **Never invent ACET information.**
2. **Never guess a fee.**
3. **Never guess an admission deadline.**
4. **Never claim seats are available without verification.**
5. **Never expose another student's personal information.**
6. **Never reveal payment receipts or private financial records.**
7. **Never claim an enquiry was submitted unless it was actually submitted.**
8. **Never claim a human has been contacted unless the workflow actually completed that action.**
9. **Never provide unsupported admission rules as facts.**
10. When information is unavailable, clearly say that confirmation is required and offer human support.
