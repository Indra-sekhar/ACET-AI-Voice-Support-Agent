# ACET AI Voice Support Agent
## PW Medharthi Capstone Project Report

### 1. Project Overview
The ACET AI Voice Support Agent is a voice-based assistant designed to help prospective B.Tech students, parents, and existing students get college information and raise support enquiries.

### 2. Problem Statement
Students and parents may need assistance with B.Tech programs, admissions, eligibility, hostel facilities, transport, and general college information. The project provides a conversational interface to answer questions from a verified knowledge base and collect enquiries for college follow-up.

### 3. Target Users
- Prospective B.Tech students
- Parents and guardians
- Existing B.Tech students

### 4. Proposed Solution
A React website connected to a Vapi voice assistant. The assistant answers supported questions using the ACET knowledge base. When information is unavailable or requires confirmation, it can offer to collect an enquiry and save the confirmed details to Google Sheets.

### 5. Main Features
- Voice-based interaction
- B.Tech information support
- Admission enquiry handling
- Knowledge-based responses
- Support enquiry collection and confirmation
- Google Sheets integration
- Error handling and human follow-up workflow
